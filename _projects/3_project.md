A conversational nutrition-tracking app with persistent user context, food-photo analysis and a recipe classification workspace.

**Key ideas tested**

- LangGraph tool calling with structured profiles, journals and conversation memory.
- Food-photo nutrition estimation with general VLMs, FoodLMM and a depth-based reproduction.
- Frozen text embeddings plus LightGBM for recipe difficulty, meal type and preparation time.
